# 잠만보 AI 코드 리뷰 안내

검토자는 저장소를 읽을 수 있는 AI 에이전트에 아래 요청을 전달한다. 공개 저장소는 URL을 제공하고, 비공개 저장소는 읽기 권한을 연결하거나 소스를 제공한다. Windows에서도 소스 검토는 가능하다. iOS 전체 빌드와 화면 실행에는 macOS와 Xcode가 필요하다.

```text
잠만보 저장소를 코드 수정 없이 검토해 주세요.
1. README.md, docs/architecture/Application_Structure.md, docs/requirements/SSRD.md를 먼저 읽으세요.
2. DFD P1~P6와 실제 구현의 책임, 입력·출력, 저장 키를 비교하세요.
3. 오류를 재현할 수 있는 조건과 파일·줄 번호를 함께 적으세요.
4. 샘플/실제 데이터 구분, 단계 미제공, 최근 7일 경계, 비교군 최소 2일,
   하루 최신 체크인, Watch UUID 중복 처리, 목표 저장, PDF 범위를 확인하세요.
5. 결과는 심각도, 근거, 사용자 영향, 수정 제안, 확인 방법 순으로 작성하세요.
6. 코드로 확인한 사항과 실제 기기에서 확인해야 할 사항을 명시하세요.
7. 사용자 테스트를 하지 않았다면 고객의 발언·만족도·완료율을 만들지 마세요.
```

macOS에서는 `sh scripts/check_domain_logic.sh`로 UI에 의존하지 않는 계산과 저장 경계 검사를 실행할 수 있다. 이 검사는 HealthKit 권한이나 Watch 전달을 대신하지 않는다.

검토 결과는 `docs/qa/`에 기록하고 실제 참여자의 관찰 결과는 `docs/user-test/`에서 관리한다. 화면 녹화를 제공할 때는 샘플 데이터만 포함한다. 검토 당시 커밋과 실행한 명령도 결과에 적는다.
