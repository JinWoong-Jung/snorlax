# P03·P05 피드백 반영과 회귀 검증

2026-11-08. 사용자가 제공한 두 피드백을 기준으로 현재 iPhone·Apple Watch 앱을 보완했다. 실제 참여자의 재시험 결과를 만들어 넣지 않았으며 아래 결과는 코드·자동 검사·개발자 시뮬레이터 검증이다.

## P03 운동과 질문·비교 설명

기존에는 운동을 저장하지 않았고 운동 표현도 질문 분류에 없었다. 운동을 iPhone·Watch 체크인, 저장·수정·이력, Watch 전송 payload에 추가했다. 값은 있음·없음·미기록의 세 상태다. 이전 JSON과 구형 Watch 메시지는 운동 미기록으로 읽으며, 미기록을 운동하지 않은 날에 포함하지 않는다.

‘운동한 날 수면이 달랐나?’, 산책·러닝·workout, 커피·카페인, 긴장·스트레스와 평균 수면의 여러 표현을 인식한다. 운동 종류·강도는 별도로 수집하지 않으므로 해당 표현은 일반 운동 여부 비교로 해석한다고 근거에 설명한다. 여러 요인을 한 질문에 넣으면 한 가지씩 선택하도록 안내한다. 모든 주제에 답하는 생성형 LLM은 추가하지 않았다.

비교는 최근 7일의 같은 기상일 수면과 하루 마지막 체크인을 결합한다. 양쪽 조건에 각각 최소 2일의 실제 수면·체크인이 있어야 두 평균과 차이를 표시한다. 날짜·출처·각 조건의 기록 수·미기록 제외 수를 근거로 제시한다. 2일은 계산의 최소 자료 수이며, 통계적 유의성이나 임상적으로 의미 있는 변화의 기준이 아니다. 평균 차이를 원인·효과로 판정하지 않는다. 샘플 수면과 개인 체크인을 결합해 결과를 만들지 않는다.

## P05 일정에 따른 조정 제안

기존 PlanEvent는 시작 시각만 저장하고 취침 계산에 사용하지 않았다. 종료 시각을 추가했고, 화면에서 시작·지속 시간을 입력한다. 이전 일정은 원래 시작 시각을 유지한 1시간 일정으로 읽으며 이 규칙을 화면에 표시한다.

기상 날짜를 명시적으로 선택한다. 기본은 다음 날 기상이며 기본 취침은 기상 목표에서 수면 목표를 뺀 시각이다. 기본 수면 구간과 겹치는 일정이 있거나 준비 시간이 부족하면 마지막 일정 종료 후 30분으로 취침 제안을 갱신한다. 기존 수면·기상 목표 자체를 몰래 변경하지 않는다.

예: 다음 날 07:00 기상·8시간 수면의 기본 목표는 전날 23:00이다. 22:00~00:00 약속을 넣으면 00:30 취침을 제안하고 확보 가능 6시간 30분, 목표보다 1시간 30분 부족을 표시한다. 8시간을 유지하는 대안 기상 시각은 08:30이다. 겹치지 않는 일정은 취침을 늦추지 않는다. 기상 목표 전에 잘 수 없으면 확보 시간을 0으로 표시하고 일정·기상 조정을 안내한다.

이는 직접 입력한 한밤의 일정 충돌을 처리하는 단순 제안이다. 외부 캘린더 동기화나 주간 최적화는 포함하지 않는다.

## P05 데이터 선택과 최종 공유 동의

공유 진입 경로를 다음과 같이 통일했다.

1. 최근 7일 중 포함할 날짜 선택
2. 총 수면·평균, 수면 단계, 체크인의 기분·스트레스·카페인·운동을 개별 선택
3. 선택된 데이터만으로 로컬 PDF 생성·미리보기
4. 체크되지 않은 최종 동의 항목을 사용자가 직접 선택
5. ‘동의하고 공유 대상 선택’으로 시스템 공유 시트 열기
6. 사용자가 앱·수신자·전송 여부 결정

기본 포함 항목은 총 수면·평균이며 수면 단계와 체크인은 기본 제외다. PDF 렌더러에는 원본 ReportSummary 대신 선택 항목만 담은 ExportReport를 전달한다. 제외한 필드·날짜를 PDF에 숨겨 넣지 않으며, 체크인을 선택하지 않으면 체크인 개수도 출력하지 않는다. 체크인 시각은 날짜까지만 출력한다.

공유 권한 검사는 동의 여부·현재 기록 스냅샷·미리보기 문서 ID를 확인한다. 기록이나 선택이 바뀌면 PDF를 다시 만들어 확인해야 한다. 공유 시트를 열면 동의 상태를 즉시 초기화하므로 취소 후 다시 공유할 때도 새 동의가 필요하다. 자동 전송이나 의료진 직접 전송 API는 없다. 선택한 항목이 많으면 PDF를 여러 페이지로 나눠 잘림을 방지한다.

## 업데이트 후 확인

Xcode에서 기존 앱을 삭제하지 않고 최신 수정본을 다시 실행한다. 운동 비교는 기존 기록을 임의로 채우지 않으므로 운동 여부와 실제 수면이 조건별 2일 이상 있어야 계산 결과가 나온다. P03·P05의 재사용 확인과 실제 Watch 운동 전달은 실제 기기에서 추가 확인한다.

01 SSRD·02 UI/UX·03 SSAD는 2026-11-08 v1.4로 원본과 제출 PDF를 재생성했다. 운동 입력·표현 변형·비교 기준, 종료 일정 반영·부족 시간·대안 기상, 선택 자료 투영·다중 페이지·최종 동의와 재시험 기준을 반영했다. [개정 내역](../submission/Submission_Document_Update_2026-11-08.md)을 참고한다. 기존 60초 영상은 변경 전 화면이므로 해당 장면 갱신이 남아 있다.
