# 잠만보 1분 시연 영상 타임라인

대상 영상: `Jammanbo_Demo_60s.mp4` · 총 60초 · 자막·오디오 없음

iPhone 시뮬레이터에서 실제 앱을 조작한 영상이다. 샘플 수면 데이터와 촬영용 체크인·일정을 사용한다. 아래 시간은 완성된 영상의 재생 시각을 기준으로 한다.

## 시간대별 내용

| 시간 | 화면·동작 | 보여주는 내용과 결과 |
|---|---|---|
| **00:00–00:07** | **오늘 — 수면 대시보드** | 최근 수면 합계 **7시간 12분**, 수면 단계, 최근 7일 평균 **7시간 4분**과 일별 그래프를 보여준다. 화면에서 샘플 데이터임을 확인할 수 있다. |
| **00:07–00:10** | **최근 7일 전체 기록** | 최근 일주일의 날짜별 수면시간을 목록으로 확인한다. |
| **00:10–00:13** | **일별 수면 상세** | 선택한 날짜의 총 수면시간과 출처, 깊은 잠·렘수면·코어 수면을 확인한다. |
| **00:13–00:15** | **체크인 입력 화면** | 기분·스트레스·오후 카페인 여부를 입력하는 화면을 보여준다. |
| **00:15–00:19** | **체크인 항목 선택** | 기분 **개운해요**, 스트레스 **낮음**, 오후 카페인 **있음**을 선택한다. |
| **00:19–00:23** | **체크인 저장 결과** | 체크인이 저장되고 최근 기록에 나타난다. 선택한 값과 입력 출처 **iPhone**, 전체 기록 **1건**을 확인한다. |
| **00:23–00:25** | **질문 화면** | 수면 기록에 질문하는 화면과 예시 질문을 보여준다. |
| **00:25–00:31** | **평균 수면 답변과 근거** | **최근 평균 수면은?**에 대해 최근 7개 기록의 평균 **7시간 4분**, 가장 최근 기록 **7시간 12분**을 표시한다. 계산에 사용한 날짜와 **샘플 기록** 출처도 함께 보여준다. |
| **00:31–00:34** | **계획 — 수면·기상 목표** | 수면 목표 **8시간**, 기상 목표 **오전 7시**, 계산된 취침 목표 **오후 11시**를 보여준다. |
| **00:34–00:39** | **수면 목표 변경** | 수면 목표를 **7시간 45분**으로 줄이면 취침 목표가 **오후 11시 15분**으로 갱신되는 모습을 보여준다. |
| **00:39–00:42** | **수동 일정 입력** | 일정 제목 **저녁 산책**을 직접 입력한다. |
| **00:42–00:46** | **수동 일정 저장** | 입력한 일정이 목록에 추가되고 날짜·시간과 함께 표시되는 것을 확인한다. |
| **00:46–00:50** | **최근 7일 요약** | 평균 수면 **7시간 4분**, 수면 기록 **7일**, 체크인 **1건**, 데이터 출처와 날짜별 수면시간을 보여준다. |
| **00:50–01:00** | **PDF 생성·내부 미리보기** | 최근 기록을 정리한 **한 페이지 PDF**를 앱 안에서 확인한다. 평균·체크인 수·출처·날짜별 수면과 단계가 포함된다. |

## 영상 설명용 요약

잠만보의 수면 기록 조회, 생활습관 체크인, 기록 기반 질문과 근거 확인, 수면 목표에 따른 취침 시각 계산, 수동 일정 저장, 요약 PDF 생성 흐름을 1분 동안 보여준다.

질문 답변은 기기 내 규칙 계산이며 생성형 LLM을 사용하지 않는다. 일정은 직접 입력하는 기능이다. 외부 캘린더 연동, 실제 HealthKit 수집·Watch 전달, PDF 외부 전송 장면은 포함하지 않는다.
