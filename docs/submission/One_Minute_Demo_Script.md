# 잠만보 1분 시연 대본

> **촬영 전용 대본입니다.** 실제 영상은 아직 촬영하지 않았습니다. Watch 체크인이 iPhone에 도착하는 것을 페어링 기기에서 확인한 뒤 녹화합니다.

## 촬영 조건

- 길이: 60초, 세로 화면, MP4
- 화면 데이터 출처가 `샘플`로 표시된 테스트 기기를 사용합니다. 실제 HealthKit 수치, 이름, 알림, 개인 계정 정보는 화면에 나오지 않게 합니다.
- Watch에서 저장한 체크인이 iPhone에 실제로 나타나는지 촬영 전에 확인합니다. 확인되지 않으면 이 장면을 성공한 기능처럼 편집하거나 설명하지 말고 촬영을 보류합니다.
- PDF는 생성 후 내용과 출처까지만 보여 줍니다. 공유 시트에서 수신자를 고르거나 전송하지 않습니다.
- 앱이 하는 일을 넘어서 실제 LLM, 캘린더 계정 연동, 수면 진단·치료 기능이 있다고 말하지 않습니다.

## 60초 화면 구성과 내레이션

| 시간 | 화면·동작 | 내레이션 |
|---|---|---|
| 0:00–0:05 | 제목 카드: `잠만보 · iPhone + Apple Watch 수면 기록 프로토타입` | “잠만보는 iPhone과 Apple Watch를 연결해 수면 기록과 아침 체크인을 함께 살펴보는 앱입니다.” |
| 0:05–0:14 | iPhone `오늘` 화면. `샘플` 출처 표시, 수면 시간과 최근 7일 평균을 차례로 보여 줌. | “오늘 화면에서 HealthKit 기록 또는 샘플 기록을 확인하고, 최근 7일의 수면 흐름을 살펴봅니다.” |
| 0:14–0:25 | Watch에서 기분·스트레스·오후 카페인을 선택하고 저장. iPhone 체크인 목록에서 새 기록과 `Apple Watch` 출처를 확인. | “기상 후에는 Watch에서 기분과 생활 맥락을 빠르게 입력합니다. 연결된 iPhone에서 전달된 체크인을 확인할 수 있습니다.” |
| 0:25–0:36 | iPhone `질문` 화면에서 `최근 평균 수면은?` 선택. 답변의 기간과 `샘플` 출처를 보여 줌. | “기록에 질문하면 기기 안의 규칙으로 답하고, 사용한 기간과 데이터 출처를 함께 보여 줍니다. 기록이 부족하면 추정하지 않습니다.” |
| 0:36–0:46 | `계획` 화면. 목표 수면 8시간과 오전 7시 기상 목표를 확인하고 취침 목표가 23시로 계산되는 장면. | “목표 기상 시각과 수면 시간을 바꾸면 취침 목표를 계산합니다. 일정은 현재 직접 입력합니다.” |
| 0:46–0:56 | `요약` 화면에서 최근 7일 요약과 데이터 출처를 보여 주고 `요약 PDF 만들기`를 누른 뒤 생성된 PDF 첫 화면을 확인. 공유는 하지 않음. | “최근 수면과 체크인을 한 페이지 PDF로 정리해, 사용자가 내용을 확인한 뒤 필요한 경우 직접 공유합니다.” |
| 0:56–1:00 | 제목 카드 아래 고지: `수면 수치는 샘플 · 기록 요약용 · 진단/치료 목적 아님` | “화면은 샘플 데이터이며, 잠만보는 수면 진단이나 치료를 제공하지 않습니다.” |

## 녹화 체크리스트

- [ ] iPhone 앱과 페어링된 Watch 앱을 실제 기기에서 실행했다.
- [ ] Watch 체크인이 iPhone에 도착하는 것을 확인했다.
- [ ] 홈과 요약 화면 모두 데이터 출처가 `샘플`로 표시된다.
- [ ] 잠금 화면 알림, 이름, 메시지, 실제 건강 기록이 노출되지 않는다.
- [ ] PDF 미리보기에는 샘플 출처만 보이고 개인 수신자나 공유 내역은 없다.
- [ ] 내레이션과 화면 동작이 맞고 영상이 60초 이내다.
- [ ] 영상 파일을 재생해 음성·글자·마지막 고지 화면을 확인했다.

Watch/iPhone 연결이 확인되지 않거나 샘플 출처를 보장할 수 없으면 공개용 영상을 녹화하지 않습니다. 시연 영상과 테스트 결과가 준비되면 [고객 사용성 테스트 패킷](../user-test/Customer_Test_Packet.md)의 실제 결과를 바탕으로 별도 3분 피드백 발표 자료를 작성합니다.
