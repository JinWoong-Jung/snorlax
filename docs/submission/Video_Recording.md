# 1분 기능 시연 영상

> v1.5 보고서에는 LLM API 연동 설계안을 추가했다. 이 저장소의 기존 영상은 로컬 규칙 기반 질문·답변이며 API 실제 호출의 증거로 사용하지 않는다. API안 설명은 설계 가정임을 구분한다.

> 2026-11-08 안내: 이 영상·대본은 P03·P05 수정 전 버전이다. 최신 앱에는 운동 입력, 일정에 따른 취침 조정, PDF 항목 선택·최종 동의가 추가되었다. 변경 내용은 [피드백 반영 보고서](../qa/Feedback_P03_P05_2026-11-08.md)를 참고한다.

편집·검수 완료: 2026-11-08. 현재 저장소의 앱을 빌드해 촬영 전용 iPhone 17 시뮬레이터에서 직접 조작하고 녹화했다. 실제 iPhone·Apple Watch의 연동 촬영본은 아니다.

## 제출 파일

- 로컬 경로: `output/video/Jammanbo_Demo_60s.mp4`
- 길이: 정확히 60.000초, 1,800프레임
- 형식: MP4, H.264, 1080×2348, 30fps
- 오디오·자막 트랙: 없음
- 데이터: 앱의 샘플 수면과 촬영용 체크인·일정. 실제 개인 HealthKit 기록은 사용하지 않음.
- 외부 업로드: 아직 진행하지 않음. YouTube URL은 업로드 후 기록한다.

장면별 화면 확인, 전체 파일 디코딩, 길이·프레임 수·해상도·비디오 단일 트랙을 확인했다. 원본은 `output/video/source/Jammanbo_Demo_Raw.mov`, 편집 기준은 같은 폴더의 `edit_timeline.json`에 보관한다. 기존 `.gitignore`에 따라 MP4·MOV는 Git에서 제외된다. 위 파일은 이 Mac의 로컬 파일이며 GitHub에 자동 게시되지 않는다.
